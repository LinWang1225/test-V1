# 渐进式 KV 量化实验结果汇总

本文整合原 A–E 实验及后续补充消融，主要结论以最新的受控离线实验为准。研究问题是：同一份 4-bit KV 编码，读取其 2/3/4-bit 前缀时，哪种编码结构和训练目标能更准确地保留注意力计算结果。

## 一、实验配置与比较口径

|项目|设置|
|---|---|
|模型|Qwen3-4B，固定 revision `1cfa9a7208912126459214e8b04321603b3df60c`，FP16 模型权重与计算|
|数据集|LongBench 六任务：qasper、hotpotqa、gov_report、trec、passage_retrieval_en、lcc|
|样本|每任务 10 条校准、15 条测试，共 60 条校准和 90 条测试；原 30 条验证请求按用户要求不执行|
|上下文与采集|Prompt 最多 8,192 token，参考生成继续 64 步；在 decode 位置 1、8、32、64 采集量化前 Q/K/V|
|覆盖范围|36 层、8 个 KV heads、32 个 query heads；固定方法使用 3 个校准请求 bootstrap 种子|
|主实验预处理|统一固定 Hadamard-sign 旋转与逐通道校准均值/Scale；每层、每 KV head、每个 K/V 侧各自使用编码表，Gaussian 表全局共享|
|存储与读取|主渐进方法的全部有效 K/V 均完整存储 4-bit；2/3-bit 必须来自同一码字的高位前缀，无 FP16 KV 尾部、不删 token、不省略第四位|
|评价方式|同一参考生成轨迹上的单层反事实 attention；FP32 参考，关闭 TF32，不让量化误差改变后续生成轨迹|

**主比较控制的是相同 4-bit 有效载荷，元数据另行计费，并非所有方法严格相同总字节。** 均值、Scale、码本和阈值都纳入账本。例如 8K 上下文下，36 层 K/V 的 4-bit 有效载荷为 288 MiB；均匀编码与逐 head 非均匀树的附加状态约为 290.4 KiB 与 336.5 KiB。后者多约 46.1 KiB。旧 `_eq` 结果通过省略部分低位支付元数据成本，不满足“每个元素完整保存 4-bit”，因此不作为本汇总的主排名。

原 A–D 有些表格采用严格等总字节口径，本文不与其混用。KVarN 使用原生分块均衡与局部 Scale/零点，属于不同的完整量化流程，将在第二部分单列。独立 2/3/4-bit 量化器也只作参考，三份编码合计 9-bit，不属于渐进主方法。

所有方法使用相同请求和参考轨迹；先在请求内部汇总种子、层、head 和 decode 位置，再对 90 条请求统计均值及配对置信区间。当前测试集的旧结果已用于指导补充方案，因此本轮属于探索性复用评估，尚需新数据或模型确认。

## 二、渐进方案总对比：指标含义、结果与原因

### 如何阅读误差指标

主指标是 **Attention Output 相对 L2 误差**。令原始 attention 的加权和输出为 O，使用重建 K/V 的输出为 O_hat：

\[
S=QK^{\top}/\sqrt{d},\quad P=\operatorname{softmax}(S),\quad O=PV,
E_O=\frac{\|\widehat{O}-O\|_F}{\|O\|_F+\epsilon}.
\]

实际计算先按每层、每个 KV head 对应的 GQA query-head 组和 decode 位置求误差，再汇总。正交旋转不改变这个范数比。**数值越低越好**：0 表示该局部 attention 输出完全一致；0.10 表示差值范数约为参考输出范数的 10%，不是准确率下降 10%，也不表示 10% 的 token 出错。误差可以超过 1，说明差值范数大于参考输出范数。这里不包含后续输出投影和跨层累计效应。

辅助指标用于定位误差来源：

|指标|说明与用途|
|---|---|
|K/V 原始 MSE|衡量数值重建误差；受原始幅度影响|
|D_K、D_V|分别为 K/V 的归一化平方误差，如 D_K = ‖K_hat−K‖² / ‖K‖²；它不是相对 L2 本身|
|Score MSE/RMSE|衡量 QKᵀ/√d 的误差，主要由 K 量化引入|
|Attention Probability L1|衡量 softmax 后关注不同 token 的概率分配变化|
|Output 相对 L2|衡量 K 和 V 误差最终如何共同影响 attention 加权和，是本文主排序依据|

不能只用 D_K/D_V 或 Score RMSE 排名：softmax 和加权求和使不同位置的误差具有不同影响。K 误差会改变“关注哪些 token”，V 误差会改变“被取出的内容”；两个侧面的误差也不能简单相加。

### 同一预处理下的主方案结果

下表 2/3/4-bit 分别表示 K2V2、K3V3、K4V4 的读取精度；底层始终保存完整 K4V4。普通 MSE 训练沿用原 C 的标准化空间，评价指标则在原始数值尺度对应的 attention 上计算。

|方案|编码或训练目标|2-bit|3-bit|4-bit|
|---|---|---:|---:|---:|
|A：均匀 MinMax|校准极值范围，均匀前缀|2.2919|0.7570|0.3105|
|均匀截断优化|校准集选择兼顾三精度的截断范围|0.5680|0.3828|0.3073|
|B：Gaussian Tree|标准正态先验递归量化树|0.5726|0.3333|0.1868|
|C：Data Tree|真实 KV 分布，逐级 MSE 聚类|0.5660|0.3044|0.1503|
|D：Jacobian Tree|K 为输出 Jacobian 权重，V 为 attention 权重|0.4656|0.2497|0.1361|
|D-K＋C-V|K 用原 D 编码，V 用原 C 编码|0.4786|0.2464|0.1277|
|Score K＋MSE V|K 用查询通道系数加权的 Score 误差代理|0.5657|0.3036|0.1504|
|Score K＋Attention V|V 改用 attention 权重|0.5534|0.3087|0.1597|
|Score K＋混合 V|V 混合普通与 attention 权重|0.5537|0.2981|0.1478|
|Jacobian K＋混合 V|K 用输出敏感性；V 两种权重各 50%|**0.4644**|**0.2393**|**0.1245**|
|仅优化 4-bit 叶编码|先拟合 16 个叶簇，粗级按叶组重建|0.5574|0.2839|0.1379|
|2/3/4-bit 联合优化|三精度重建损失等权联合优化|0.5634|0.2994|0.1472|

**在统一预处理、无 FP16 KV 保留的主候选中，Jacobian K＋混合 V 的平均输出误差最低。** 相对 Data Tree，2/3/4-bit 分别下降 17.96%、21.37%、17.15%，配对 95% CI 分别为 [17.09%, 18.82%]、[20.38%, 22.42%]、[16.25%, 18.14%]，均超过预设 5% 实用收益门槛。整体最优不代表每一层和每个 head 都最优，部署前仍需检查局部退化。

这一结果说明，K 和 V 不必采用完全相同的训练目标。K 的输出敏感性除了查询系数，还与 token 的 attention 概率、该 token 的 V 和当前输出的差异有关；只降低查询加权的 Score 误差代理，未必优先修复最影响输出的位置。本轮简单 Score K＋MSE V 相对 C 的变化约为 +0.05%、+0.27%、−0.04%，几乎没有实用收益，而 Output-Jacobian K 的收益明显更大。

本轮 V 的结果也显示，只采用 attention 权重并未取得最佳整体折中。D-K＋C-V 在 3/4-bit 优于原 D，但在 2-bit 更差；将 V 的普通权重和归一化 attention 权重各取 50%，则在这三种精度下得到更好的整体折中。一个合理解释是，混合目标既照顾重要位置，也保留对一般样本的重建能力。实测支持这种折中，但尚未单独证明原 V 退化究竟由样本代表性、校准偏差还是目标近似造成。

**功能误差与整体重建误差的排序确实不同。** 例如 4-bit 时，Jacobian K＋混合 V 的 D_K 为 0.005715，高于 C 的 0.004478，但输出误差为 0.1245，低于 C 的 0.1503。因此，数据驱动树适合降低整体重建失真，注意力感知权重则可以通过改变误差分布进一步保护最终输出。

多精度联合优化相对 C 只改善约 0.47%、1.64%、2.08%，未达到 5% 门槛；仅优化 4-bit 叶编码反而在本轮输出指标上更好。这并不说明联合训练普遍无效：当前联合目标是标准化重建损失，三精度等权也不等于三精度对 attention 输出同样重要。结果更直接地提示，继续优化功能目标可能比仅联合重建 MSE 更有效。

### KVarN 参考与渐进读取的适用边界

KVarN 的两种恢复方式也都使用同一个原生 4-bit 码字：“中点”用缺失低位区间的中心恢复，“补零”将缺失位填零；两者均不新增学习码本。其结果单列如下，不能与上表合并解释为只改变码本的实验：

|KVarN 条件|2-bit|3-bit|4-bit|
|---|---:|---:|---:|
|旧 E：保留 FP16 尾部，中点恢复|0.1347|0.0486|0.0177|
|全部有效 KV 量化，中点恢复|0.2235|0.0939|0.0411|
|全部有效 KV 量化，补零恢复|0.8945|0.2983|0.0411|

去掉 FP16 尾部后误差明显增加，说明旧 E 的精度优势确有一部分来自保护尾部。中点恢复明显优于补零，与补零总选择粗区间下沿、容易形成有方向的重建偏差相一致；误差并不必然在 attention 求和时抵消。4-bit 没有缺失位，两个恢复版本因而一致。

全部 KV 量化的 KVarN 仍有较低输出误差，但它按当前块实时均衡，并使用更细的局部 Scale/零点，和主实验的共享校准状态不同，也付出更多元数据。例如完整 8K 场景下，原生块元数据约 27 MiB，主共享树方案的全部附加状态约 0.329 MiB。**因此可以说 KVarN 整套流程在这些指标上更好，不能说均匀码点本身已经击败非均匀码点。** 该组保留必要的 FP16 Scale/零点；取消的是 FP16 KV 数据保留，任意短尾使用有效 token 的参考量化分支。

对于后续动态读取，本轮已保存每级失真、边际收益和读取预算曲线。float64 下 275,400 个抽取的 8-item、校准代理目标预算实例中，贪心与精确 DP 差距均为零；但测试 token/channel 的固定抽样仍存在局部收益递减违反，不能据此继承全局最优性保证。动态原型只覆盖 L0/L17/L35、decode 1/64 和首种子；尚未测量真实 HBM 流量、在线 Kernel 延迟或端到端质量。

## 三、均匀与非均匀量化对比：优势出现在哪里

这里比较的是主实验共同预处理和粒度下的编码家族，而不是 KVarN 整套流程。均匀方案已经优化校准截断范围，避免只用容易受极值影响的原始 A 作为对照。普通 MSE 目标下，结果为：

|读取精度|均匀嵌套 U_Clipped|非均匀嵌套 Data Tree|非均匀相对改善|
|---:|---:|---:|---:|
|2-bit|0.5680|0.5660|0.35%|
|3-bit|0.3828|0.3044|20.47%|
|4-bit|0.3073|0.1503|51.08%|

改善比例统一定义为 1−非均匀误差/均匀误差，正值表示非均匀更好。**本轮 2-bit 基本相当，3/4-bit 非均匀分别降低约 20% 和 51% 的输出误差。** 原 A 的 2-bit 为 2.2919，优化截断后降至 0.5680，说明原均匀基线的巨大劣势相当一部分来自范围选择，而不能直接解释为均匀结构本身不合适。

换成不同 K/V 目标后，非均匀相对均匀的改善如下。每一行的两个编码家族采用相同类型的目标：

|优化目标|2-bit|3-bit|4-bit|
|---|---:|---:|---:|
|Score K＋MSE V|+0.26%|+20.62%|+51.04%|
|Score K＋Attention V|-2.25%|+18.77%|+49.32%|
|Score K＋混合 V|+0.16%|+20.52%|+51.09%|

这些交叉结果表明，3/4-bit 的非均匀收益并非只出现在单一目标上；2-bit 则没有稳定优势，在 Attention V 目标下均匀还略好。只有 4 个粗重建值时，两类方案的表达能力都很有限，优化范围后可能已经相近；增加到 8/16 个重建值后，非均匀编码可以将更多码点分配到高概率或高权重区域，而均匀编码必须保持等间距。这是与结果一致的机制解释，尚不是对各误差来源贡献的单独因果分解。

均匀渐进方案还存在一个额外折中：本轮 U_Clipped 用同一个截断范围，最小化 2/3/4-bit 重建损失的平均值。虽然系数等权，但 2-bit 的绝对失真通常更大，范围选择会更多受到粗精度损失影响。一旦幅值被截断，后续增加 bit 也不能恢复被裁掉的部分，因此其 4-bit 不一定接近独立训练的最优范围。

独立训练各精度的参考进一步揭示了这个代价：

|独立精度参考|2-bit|3-bit|4-bit|
|---|---:|---:|---:|
|独立均匀|0.5776|0.3570|0.1901|
|独立非均匀|0.5660|0.2958|0.1382|

独立 4-bit 下，非均匀相对均匀改善约 27.31%，小于渐进方案的 51.08%。这说明渐进均匀方案较大的差距，还包含共享范围和嵌套训练的折中，不能把全部差距都归因于等间距码点。独立参考属于有限网格或局部 Lloyd 拟合，不是已证明的全局最优上限，也不满足单份 4-bit 码字前缀读取约束。

因此，本轮较稳妥的研究判断是：**在统一预处理下，2-bit 应保留优化后的均匀编码作为竞争基线；3/4-bit 更支持非均匀嵌套编码。训练目标上，优先继续检验 K 的输出敏感性与 V 的混合目标。** 若要解释 KVarN 的更低误差，应另外拆分分块均衡、元数据粒度与尾部处理的贡献，不能将该排名直接当成均匀/非均匀结构之争的答案。

## 四、各方法如何实现，以及与论文的对应关系

### 4.1 哪一种方法参考了 Any-Precision？

**C：Data Tree 是对 Any-Precision “先训练低精度种子，再逐簇二分增加精度”方法的直接 KV 适配基线。D、D-K＋C-V、各类 Score/Attention/Mix 非均匀树沿用同一个逐级分裂框架，主要区别是训练权重或 K/V 两侧码本的组合。**

Any-Precision 原文借助 SqueezeLLM 构建低精度种子，通过带敏感性权重的一维 K-means，把已有每个簇分成两个子簇，每次增加一个索引位。论文主要量化的是**模型权重**，其敏感性来自近似二阶导；本实验量化的是**运行时 KV 激活**，将种子设为 2-bit、最大深度设为 4-bit，并改用 KV 经验分布或 attention 功能敏感性。论文主要评估使用 3-bit 种子逐步扩展到更高精度，本实验没有复现其整套权重量化、梯度计算或 CUDA 推理引擎。

因此，C 保留论文的增量聚类结构，但把敏感性简化为样本频率；D 等则保留加权聚类思路，换成 KV 专用权重。**这些都应称为参考 Any-Precision 的 KV 适配，不能把本表某一行直接标为“Any-Precision 原论文复现结果”。** B：Gaussian Tree 的直接依据是 ReadKV 的 Gaussian 递归树；仅优化 4-bit 叶编码、联合优化和收益正则是本实验的其他消融变体。

依据：[Any-Precision 论文副本](references/Any-precision.pdf)、[官方实现快照](references/any-precision-llm/any_precision/quantization/quantize.py)。官方 `_seed_and_upscale_layer` 对应种子聚类，`_increment_group` 对应已有簇的二分扩展。

### 4.2 先理解共同的编码与重建过程

主实验先将旋转后的标量标准化为 `z = (x_rot − mean) / scale`。每层、每个 KV head、K/V 两侧分别拟合编码参数；测试时这些参数冻结。量化器把 z 编成一个 0–15 的 4-bit 索引，再从它的前缀解码，最后用 `x_hat_rot = mean + scale × z_hat` 恢复数值尺度。

例如，一个标量的完整码字为 `1011`：

|读取深度|读取的索引|均匀量化如何重建|非均匀树如何重建|
|---|---|---|---|
|2-bit|`10`，即 2|恢复原 INT4 索引区间 8–11 的中心 9.5，再代入线性反量化|查 2-bit 表的第 2 个质心|
|3-bit|`101`，即 5|恢复原 INT4 索引区间 10–11 的中心 10.5，再代入线性反量化|查 3-bit 表的第 5 个质心|
|4-bit|`1011`，即 11|使用完整 INT4 索引 11|查 4-bit 表的第 11 个质心|

“前缀重建”不等于为每个精度重新寻找最近码点，也不等于为非均匀树把缺失位补零后查 4-bit 表。非均匀方案明确保存各精度的重建表；它们按模型共享粒度计费，不是逐 token 新增码本。

均匀方案用两个范围参数 `lo/hi` 表示 16 个等间距码点：

```text
q4 = clamp(round((z − lo) / (hi − lo) × 15), 0, 15)
qb = q4 >> (4 − b)
q_hat4 = qb × 2^(4 − b) + (2^(4 − b) − 1) / 2
z_hat = lo + q_hat4 / 15 × (hi − lo)
```

非均匀树的分支与质心由训练决定。其 2-bit 有 4 个重建值，3-bit 有 8 个，4-bit 有 16 个；存储 28 个 FP16 质心和 15 个 FP16 分界值，共 86 字节/树。均匀范围是两个 FP16 数，共 4 字节。共同的均值/Scale、动态分配曲线等状态另外计费。

### 4.3 基础编码结构：A、U-Clipped、B、C 有什么不同？

|文档名称 / 代码名称|实际实现|与其他方案的关键区别|
|---|---|---|
|A：均匀 MinMax / `U_MinMax`|在校准样本标准化后，逐层/head/侧取最小值、最大值作为固定 lo/hi，使用上述均匀 INT4 编码与中点前缀恢复|只确定范围，不训练非均匀质心；极端值可能拉大量程|
|均匀截断优化 / `U_Clipped`|在校准集上枚举上下尾截断分位数 `{0, 0.0001, 0.001, 0.005, 0.01, 0.02}` 的 36 组组合；对同一路径的 2/3/4-bit 重建损失求平均，选最优 lo/hi|仍是均匀码点，只优化范围；不是分别为三种精度训练三个范围|
|B：Gaussian Tree / `Gaussian_Tree`|用标准正态分布的确定性分位点近似积分，从根节点递归二分到 4-bit；每个区间内用二簇 Lloyd 更新，保存子区间质心与分界|码点分配依据固定 Gaussian 先验；不按真实 KV 样本重新拟合树，直接参考 ReadKV 的编码方法|
|C：Data Tree / `Data_Tree`|用真实校准 KV 样本先训练 4 簇，形成 2-bit 种子；每个簇分别二分得到 8 簇，再分别二分得到 16 簇。父级结构和重建表在后续分裂中保留|树适应真实 KV 分布；这是本实验对 Any-Precision 增量聚类结构的直接适配|

C 的分裂过程可写成：`4 个种子簇 → 每簇拆成 2 个 → 8 簇 → 每簇再拆成 2 个 → 16 簇`。拆分只能发生在原父簇内部，因此 4-bit 叶索引的高 2/3 位自然就是祖先簇索引。它不是先训练独立 16 簇，再回头任意合并。

经验分布拟合使用 8,192-bin 加权充分统计近似。C 的普通 MSE 指标准化 z 空间的误差，bin 的样本频率和请求 bootstrap 次数形成权重；不是直接最小化完整 attention 输出误差。聚类采用加权均值更新质心，分界通常取相邻质心中点。新增优化记录保留迭代与损失历史，旧 C/D 则复用冻结码本。

### 4.4 训练权重与 K/V 组合：D、Score、Mix 分别是什么？

这些非均匀方法采用与 C 相同的“2-bit 种子＋逐簇二分”结构。改变的是校准样本对聚类损失的贡献，以及 K/V 两侧选用的编码表。共同形式为：

```text
聚类损失 = Σ 样本频率 × 敏感性权重 × (z − 对应簇质心)^2
```

权重越大，训练越倾向于减少这些样本的重建误差。所有权重都在校准请求上计算；不会在测试时依据当前 query 重新训练码本。下面 q、v、o 都指共同旋转空间中的校准参考数据，p 是对应 attention 概率，σ 是标准化 Scale，h 遍历共享同一 KV head 的 query heads。

|目标名|本实验使用的权重|直观含义|
|---|---|---|
|普通 MSE|敏感性权重为 1|按经验频率拟合标准化 KV 分布|
|K Score-aware|`Σ_h q[h,c]^2 × σ_K[c]^2 / d`|查询系数较大的通道，其 K 误差更容易改变 score；这是对角代理，不是直接优化完整 score 张量|
|K Output-Jacobian|`Σ_h p[h,t]^2 × ‖v[t]−o[h]‖² × q[h,c]^2 × σ_K[c]^2 / d`|同时考虑查询通道、token 概率以及该 token 内容与当前输出的差异，近似衡量 K 标量误差对输出的影响|
|V Attention-aware|`Σ_h p[h,t]^2 × σ_V[c]^2`|V 标量误差通过 attention 加权进入输出；高权重位置受到更多保护|
|V 混合目标|`0.5 + 0.5 × normalized_attention_weight`|一半为普通权重，一半为均值归一化到 1 的 attention 权重，避免完全忽略低权重样本|

敏感性权重在对应 head 的校准分布上做均值归一化，频率权重另外保留。K 的 Jacobian 和 V 的 attention 权重来自局部输出导数的平方范数，忽略误差交叉项；**它们不是 Any-Precision 原文对模型参数使用的二阶任务损失敏感性，也不是完整端到端任务 loss 的优化。**

各行方法名的实际含义如下。表中“C-K/C-V”表示普通 MSE 树，“D-K”表示原 D 的 Jacobian K 树，“D-V”表示原 D 的 attention V 树。

|文档名称 / 代码名称|K 使用什么|V 使用什么|究竟改变了什么|
|---|---|---|---|
|D：Jacobian Tree / `Jacobian_Tree`|D-K|D-V|保留 C 的逐级聚类结构，分别用上表两侧的功能敏感性权重|
|D-K＋C-V / `JacK_MSEV`|复用 D-K|复用 C-V|组合两套已冻结码本，重新计算真实联合 attention；不是把两个单侧误差相加|
|Score K＋MSE V / `ScoreK_MSEV`|新拟合的 Score-aware 树|C-V|只替换 K 的训练权重，V 保持普通分布拟合|
|Score K＋Attention V / `ScoreK_AttnV`|Score-aware 树|D-V|K 用 score 代理，V 用 attention 权重|
|Score K＋混合 V / `ScoreK_MixV`|Score-aware 树|新拟合的混合目标树|保留 Score K，缓解 V 只按 attention 训练的偏向|
|Jacobian K＋混合 V / `JacK_MixV`|D-K|混合目标树|K 保持输出敏感性，V 使用普通/attention 各 50% 的权重；本轮主候选中整体输出误差最低|

因此，D、Score 和 Mix **不是三种不同的位打包格式**，它们主要是在相同树结构上改变训练目标。D-K＋C-V 等名称表示两侧编码表的组合，不表示 K/V 读取位宽不同；主表每一列仍分别是 K2V2、K3V3、K4V4。

均匀家族也做了相同目标类型的交叉实验，区别是权重用于选择截断范围，而不是学习非均匀簇中心：

|代码名称|K 的均匀范围如何选|V 的均匀范围如何选|对应的非均匀对照|
|---|---|---|---|
|`Uniform_ScoreK_MSEV`|以 Score 权重评价 36 组范围|普通 MSE|`ScoreK_MSEV`|
|`Uniform_ScoreK_AttnV`|Score 权重|Attention 权重|`ScoreK_AttnV`|
|`Uniform_ScoreK_MixV`|Score 权重|混合权重|`ScoreK_MixV`|

这些均匀变体仍共用一份 4-bit 索引及前缀中点重建，并以三个精度的加权损失平均值选范围。这里统一的是权重与目标类型，均匀范围搜索和非均匀逐级聚类的优化算法仍不同，不能称为两类编码各自数学全局最优解的严格比较。

### 4.5 仅优化 4-bit、联合优化、独立参考有什么区别？

|文档名称 / 代码名称|训练流程|与 C 的区别及状态|
|---|---|---|
|仅优化 4-bit 叶编码 / `Leaf4_Only`|先以普通 MSE 拟合 16 个有序叶簇；相邻 4 个叶组成一个 2-bit 组，相邻 2 个叶组成一个 3-bit 组；粗级重建取组内样本的加权均值|先细后粗，训练优先照顾 4-bit；不是 Any-Precision 的先粗后细扩展|
|2/3/4-bit 联合优化 / `Joint_234`|从 C 的树开始，交替更新有序叶分界和各级重建值，最小化 `(D2+D3+D4)/3`；最多 60 轮，相对改善阈值为 1e-6|可以回调粗级分区，粗细精度共同决定最终编码；C 后续分裂则不回调已有父分区|
|联合优化＋收益递减正则 / `Joint_Regularized`|若校准 head 曲线的归一化违反幅度达到 0.01，在联合树的固定分区上调整各级质心，惩罚非单调和收益不递减；λ=10、Adam 100 步、学习率 0.01|仅为条件阶段；本轮没有 head 达到触发门槛，因此未进入正式结果排名，不能声称已验证正则收益|
|独立非均匀参考 / `Independent_MSE`|分别拟合 4、8、16 个簇，各精度单独选择最近簇并编码|三套编码互不要求前缀对应；用于估计嵌套约束的代价，不是渐进方法|
|独立均匀参考 / `Independent_Uniform`|每个精度分别搜索截断范围，并按该精度的 4/8/16 个等间距码点独立编码|不需要用同一个范围兼顾三个精度，也不要求低位宽来自 4-bit 前缀|

这里的 D2/D3/D4 是对应校准重建目标，不是第二部分结果表中的 attention 输出误差。联合优化没有直接对完整 attention 输出做梯度训练。独立参考如果同时保存三种编码，需要 2+3+4=9 bit/标量，因此不能用其结果冒充同一份 4-bit 存储下的正式排名。

本轮实际评估 17 个主流程方法变体：包括上面的 12 个主表方案、3 个均匀目标交叉方案和2个独立参考；`Joint_Regularized` 是第18个预注册候选，但因条件未触发而跳过。KVarN 是另外运行的补充组。

### 4.6 KVarN 的 E、中点、补零及去 FP16 保留是什么意思？

E 直接调用冻结的 KVarN 量化源码：原生 Hadamard FP16 旋转 → 128-token 块内行列方差均衡 8 次 → K 按通道、V 按 token 做非对称 INT4 范围量化 → 保存原生 FP16 absorbed Scale/零点及另一轴均衡因子。它会根据当前块计算局部参数，而不是使用主实验跨请求共享的码本。局部参数及其存储成本均保留。

|名称 / 代码名称|完整块|未满块尾部|前缀恢复|
|---|---|---|---|
|旧 E / `E`|原生 KVarN INT4|保留 FP16 KV|缺失低位按原 INT4 索引区间中点恢复|
|旧 E 补零 / `E_zero`|相同原生 INT4|保留 FP16 KV|缺失低位填零，相当于选择该码字区间下沿|
|去 FP16 保留 / `KVARN_nt`|完整块与旧 E 保持一致|按有效 token 均衡并量化成 4-bit，无原始 KV 旁路|中点恢复|
|去 FP16 保留、补零 / `KVARN_nt_zero`|同上|同上|补零恢复|

任意短尾采用 PyTorch 有效 tile 参考分支，不让填充值或未来 token 进入统计；单 token 退化块跳过无定义的方差均衡。必要的 FP16 Scale/零点仍计费。“去 FP16”仅指取消 FP16 KV 数据保留，不是把所有元数据也改成 4-bit。

**2/3-bit 前缀恢复是本实验在原生 INT4 码字上增加的离线重建逻辑，不代表直接调用了 KVarN 原生 3-bit 在线推理 Kernel。** `_eq` 则是旧实验的预算包装：通过省略部分最低位平面支付额外元数据，既不是新聚类目标，也不满足本轮“每个元素完整保留 4-bit”的主条件，故只保留为历史辅助结果。

同样，动态读取不是新增的一种码本：它在已冻结编码上，根据当前 Q 和校准失真曲线选择 K 的读取深度，再用重建 K 的 attention 选择 V 的读取深度。它改变“读多少位”，不改变“最初如何编码”。
